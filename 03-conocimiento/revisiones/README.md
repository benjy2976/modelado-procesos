# Eventos de revision

[Inicio](../../00-inicio.md) · [Conocimiento estructurado](../README.md)

Cada archivo representa una accion humana auditable sobre una regla. Los eventos registrados no se modifican ni eliminan; una correccion se expresa mediante un evento posterior que referencia al anterior.

No se incluyen datos personales innecesarios. Se utiliza el identificador institucional autorizado del participante y su rol o especialidad.

Se rigen por el [Protocolo de conocimiento confiable](../../00-gobernanza/protocolo-conocimiento-confiable.md).
