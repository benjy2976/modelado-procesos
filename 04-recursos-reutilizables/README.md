# Recursos reutilizables

Plantillas, actores, sistemas, documentos, reglas de negocio, riesgos, controles, indicadores y componentes BPMN comunes a varios procesos.

`conocimiento/` conserva las reglas atomicas y los eventos de validacion humana. Las plantillas de regla, evento y paquete de contexto se encuentran en `plantillas/`.
