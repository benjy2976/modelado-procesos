# Derivados de texto

El subdirectorio `cache/` se crea localmente para las extracciones Markdown reproducibles. Su contenido no se versiona y puede regenerarse desde los originales mediante el extractor documental previsto en `05-herramientas/extractor-documental/README.md`.

Una extraccion facilita la busqueda y el trabajo con IA, pero no sustituye el original ni constituye conocimiento validado. Las reglas curadas se almacenan en `03-conocimiento/`.
