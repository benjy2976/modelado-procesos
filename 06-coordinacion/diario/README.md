# Diario

[Inicio](../../00-inicio.md) · [Coordinacion](../README.md)

La configuracion portable de Obsidian crea notas en `YYYY/MM/YYYY-MM-DD.md` mediante la plantilla `diario.md`.

El diario es captura transitoria. El conocimiento durable se promueve al area que corresponda y se somete a sus validaciones.
