# Bases

[Inicio](../../00-inicio.md) · [Coordinacion](../README.md)

Esta carpeta contiene Bases transversales. Una Base consulta archivos y propiedades; no conserva conocimiento exclusivo ni reemplaza los YAML, Markdown, CSV o BPMN que actuan como fuente maestra.

## Vistas disponibles

- [Catalogo de documentacion](documentacion.base): muestra las notas que declaran `tipo`, junto con area, estado y clase de conocimiento.

Las nuevas Bases se incorporan cuando el conjunto de notas objetivo cuenta con propiedades consistentes y vocabularios validados.
