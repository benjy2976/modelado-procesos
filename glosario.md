# Glosario vivo

| Termino | Definicion de trabajo | Fuente pendiente |
|---|---|---|
| CDE | Entorno Comun de Datos para gestionar contenedores de informacion y sus estados. Es un concepto BIM; este repositorio no se declara como el CDE institucional. | Si |
| WIP | Informacion en elaboracion. En el repositorio corresponde al arbol de trabajo y sus commits, no a una carpeta. | Si |
| Compartido | Informacion emitida para coordinacion o revision. Se representa mediante rama/solicitud de cambio o pre-release, no mediante una copia. | Si |
| Publicado | Linea base autorizada para un uso previsto e identificada mediante tag y release. | Si |
| Archivo | Historial inmutable de releases reemplazadas o retiradas, conservado por Git y la forja. | Si |
| Release | Paquete inmutable asociado a un tag Git que identifica una linea base y sus derivados. | No |
| Regla normativa | Enunciado atomico trazable que estructura una obligacion, prohibicion, permiso, condicion, definicion o recomendacion de una fuente. | No |
| Regla validada | Regla cuya cita, vigencia, aplicabilidad e interpretacion fueron confirmadas por un especialista y registradas en un evento auditable. | No |
| Paquete de contexto | Conjunto minimo y autorizado de archivos, reglas y evidencias entregado para una tarea humana o asistida por IA. | No |
| EVIDENCIA-INSUFICIENTE | Marca usada cuando las fuentes autorizadas no permiten sostener una conclusion sin inventar o inferir indebidamente. | No |
| BPMN | Notacion estandar para modelar procesos de negocio. | Si |
| Fuente maestra | Archivo autorizado en el que se modifica directamente un tipo de informacion y del cual se obtienen sus derivados. | No |
| Modelo logico | Representacion conceptual de responsabilidades, actividades, decisiones y transferencias; en esta iniciativa se expresa temporalmente mediante PlantUML. | No |
| Modelo formal | Modelo BPMN 2.0 XML que conserva la semantica y disposicion aprobada para revision o linea base. | No |
| PlantUML | Notacion textual utilizada para construir modelos logicos con carriles y generar vistas SVG durante el levantamiento. | No |
| Derivado | Archivo generado desde una fuente maestra, como SVG, PDF, resumen Markdown o reporte; no se edita manualmente. | No |
| Iniciativa | Cambio o capacidad transversal documentada con alcance, arquitectura, fases, riesgos, pruebas y criterios de aceptacion. | No |
| Nivel de proceso | Clasificacion de los procesos segun su desagregacion: el nivel 0 o macroproceso es el mas agregado y se desagrega en nivel 1, nivel 2 hasta el ultimo nivel n. NT 002-2025-PCM-SGP, glosario, pagina PDF 22. | No |
| Ficha de producto y proceso | Documento que registra y describe los elementos de la caracterizacion de un proceso e incluye su diagrama. NT 002-2025-PCM-SGP, numeral 6.1.3 a y Anexo 2. En el proyecto es la fuente del PDF a aprobar. | No |
| Procedimiento | Descripcion de las tareas de un proceso de ultimo nivel; solo se elabora si cumple algun criterio y como maximo uno por proceso. NT 002-2025-PCM-SGP, numeral 6.1.3 d y Anexo 7. | No |
| Dueno del proceso | Unidad de organizacion con responsabilidad y autoridad para disenar, implementar, controlar y mejorar el proceso; elabora y aprueba su documentacion. NT 002-2025-PCM-SGP, Anexo 2 y numeral 6.1.4. | No |
| Sustento | Archivo de cada proceso que registra fuentes, evidencias, clase de cada afirmacion, vacios, discrepancias e historial de revision; no se exporta (`DEC-017`). | No |
| Propuesta | Todo documento de proceso aun no aprobado. Tambien designa el unico archivo `-propuesta` con que se plantea variar un documento aprobado (`DEC-017`). | No |
| Nivel de revision | Etapa del circuito de un documento de proceso: `ELABORACION`, `REVISION-EQUIPO`, `OPINION-TECNICA` y `APROBACION` (`DEC-017`). | No |
| EIR | Requisitos de intercambio de informacion. | Si |
| BEP | Plan de Ejecucion BIM. | Si |
| MIDP | Programa general de desarrollo de la informacion. | Si |
| TIDP | Programa de desarrollo de informacion de una tarea. | Si |

Las definiciones se actualizaran con cita exacta al incorporar la documentacion oficial BIM.
