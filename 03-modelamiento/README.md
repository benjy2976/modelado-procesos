# Modelamiento

[Inicio](../00-inicio.md)

Esta carpeta contiene el trabajo vigente producido por el equipo, organizado por proceso y tipo de artefacto. No replica estados WIP, Compartido, Publicado o Archivo: Git conserva el historial y `00-gobernanza/protocolo-versionado-y-releases.md` regula las lineas base.

Cada proceso mantiene separados el levantamiento AS-IS, el analisis y el diseno TO-BE. BPMN 2.0 XML es la fuente maestra de los diagramas; SVG y PDF son derivados.
