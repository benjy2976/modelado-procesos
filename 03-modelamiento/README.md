# Modelamiento

[Inicio](../00-inicio.md)

Esta carpeta contiene el trabajo vigente producido por el equipo, organizado por proceso y tipo de artefacto. No replica estados WIP, Compartido, Publicado o Archivo: Git conserva el historial y `00-gobernanza/protocolo-versionado-y-releases.md` regula las lineas base.

Cada proceso mantiene separados el levantamiento AS-IS, el analisis y el diseno TO-BE. PlantUML se usa para modelos logicos durante el levantamiento; BPMN 2.0 XML es la fuente maestra de los modelos formales; SVG y PDF son derivados. El mapa institucional de procesos Nivel 0 queda fuera de este flujo y permanece como representacion conceptual lineal en Markdown/Mermaid.
